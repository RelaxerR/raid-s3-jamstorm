# Одиночная игровая сессия

[Реестр](../components.md) · [Приложение](application.md) · [Лодка](boat.md) · [Груз](cargo.md) · [Порт](port.md)

`SecondCatch.Solo.SoloGameSession` — чистая C# модель, создаётся GameApplication на новую игру. Владеет BoatState, FishCargo, Coins, AtSea и монотонной Revision. Изменения проходят через команды, Unity-объекты здесь не хранятся. Все команды вызываются последовательно на основном потоке.

Depart/Dock возвращают false при повторе. CatchFish работает только в море, Sell и BuySpeedUpgrade — только в порту. Damage игнорирует неположительный урон и порт. При гибели правила потери применяются один раз; новая сцена не создаёт новую сессию. Revision увеличивается только при принятых командах.

В отличие от старой Foundation.GameSession нет Join, сетевых операторов, shared host authority, охоты на духа и прямой выдачи денег за охоту. Интеграции v2 должны использовать SoloGameSession, не смешивая две модели.

Модель пока не содержит ремонта, древесины, контрактов, экипажа и дисковых сохранений. Это явные [следующие этапы](../scope.md), а не успешные заглушки.
