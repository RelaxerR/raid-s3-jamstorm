# Одиночная игровая сессия

[Реестр](../components.md) · [Приложение](application.md) · [Лодка](boat.md) · [Груз](cargo.md) · [Порт](port.md)

`SecondCatch.Solo.SoloGameSession` — чистая C# модель, создаётся GameApplication на новую игру. Владеет BoatState, FishCargo, Coins, Wood, AtSea и монотонной Revision. Изменения проходят через команды, Unity-объекты здесь не хранятся. Все команды вызываются последовательно на основном потоке.

Depart/Dock возвращают false при повторе. CatchFish и CatchSchool работают только в море. При успешном CatchSchool сессия запоминает ID косяка до следующего Depart. Sell, SellFish, BuyWood и BuySpeedUpgrade работают в порту. Damage записывает урон в одну зону и игнорирует неположительный урон и порт. TryRepairZone в море списывает одну древесину и восстанавливает повреждённую зону. При гибели правила потери применяются один раз, а сцена порта продолжает использовать ту же сессию. Revision увеличивается только при принятых командах.

В отличие от старой Foundation.GameSession нет Join, сетевых операторов, shared host authority, охоты на духа и прямой выдачи денег за охоту. Интеграции v2 должны использовать SoloGameSession, не смешивая две модели.

Контракты, экипаж и дисковые сохранения запланированы на [следующие этапы](../scope.md).
