# Рыба, косяк и бочка

[Реестр](../components.md) · [Сессия](session.md) · [Порт](port.md) · [Дух](spirit.md)

`FishCargo` — одна бочка серого каркаса, FishId=fish.greybox, вместимость 100, Count только для чтения снаружи. Другой тип и переполнение отвергаются. Потеря при гибели сохраняет floor(Count/2); округление требует согласования. Продажа очищает бочку один раз.

`FishSchool` — источник одного улова. Сериализованная ссылка на HomeShallowsController; TryCollect вызывается будущим проверенным контактом лодки. При полном трюме источник остаётся доступным, при успехе помечается собранным и выключается. Количество рыбы в косяке, респавн косяков и визуал не реализованы.

Срез требует набора бочек (2 на первом транспорте), одного вида на каждую, каталога цен и редкости, рыбы на палубе, ручных сетей и отдельной ёмкости уникальной рыбы. Текущая бочка — ограничение серого каркаса. Старая Foundation.FishDefinition не является каталогом v2.
