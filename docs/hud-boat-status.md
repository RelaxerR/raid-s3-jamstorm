# Статус лодки

[Структура HUD](gameplay-hud.md) · [Компас](hud-compass.md) · [Будущие индикаторы](hud-future-indicators.md)

`BoatStatusPanel` получает один `BoatController` от корневого HUD. Данные принадлежат той же лодке, которая движется в graybox. Никаких демонстрационных значений скорости или состояния паруса UI не вычисляет.

| Данные | Публичный источник | Отображение |
| --- | --- | --- |
| Прочность | `HitPoints`, `MaxHitPoints` | Текущий/максимальный HP и полоса |
| Скорость | `CurrentSpeed` | Одна цифра после запятой, мировые единицы/с |
| Парус | `SailRaised`, `SailAngle` | Поднят / опущен, относительный угол в градусах |
| Эффективность угла | `SailEfficiency` | Процент от 0 до 100 для текущего направления ветра |
| Ветер | `Wind.Direction`, `Wind.Speed`, `Wind.Strength` | Направление куда дует, базовая скорость и множитель силы |
| Источник тяги | `SailSpeedContribution`, `RowingSpeedContribution` | Парус / Руль / Парус + руль / Инерция / Стоянка |
| Отклонение руля | `Steering` | Прямо / влево / вправо |

Направление ветра показано азимутом: 000° — мировой +Z (север), 090° — +X (восток). Это направление **куда** дует ветер; компас по-прежнему показывает отдельно курс корпуса. При отсутствующем или отключённом компоненте выводится «Ветер: недоступен». Эффективность описывает настройку угла и может быть 100% при опущенном парусе, но вклад тяги тогда равен нулю. [Модель движения](boat-wind-movement.md) содержит формулу и таблицу углов.

Источник определяется положительными целевыми вкладами до общего ограничения скорости: «Парус», «Руль» или оба. При нулевых вкладах и сохраняющейся скорости показывается «Инерция», после полной остановки — «Стоянка». Руль как источник означает греблю; одна коррекция курса без гребли не добавляет этот источник. «Прямо» означает модуль сглаженного руля ниже 0.01.

Панель расширена до 520 × 270, текст — 488 × 222; режим игрока перенесён ниже панели. Все данные обновляются существующим `GameplayHud.LateUpdate`, UI не рассчитывает тягу и не обрабатывает ввод.

Прочность добавлена как минимальное локальное состояние `BoatController`: сериализованные `_hitPoints = 100`, `_maxHitPoints = 100`, чтение с ограничением допустимого диапазона и публичный `SetHitPoints(float)`. UI только читает это состояние. Полоса изменяет правый якорь `Image` пропорционально HP, поэтому ей не нужен спрайт.

В сцене ещё нет урона, столкновений лодки и ремонта. Поэтому HP остаётся 100/100 до явной команды внешнего источника или изменения настроек. Это действительное значение локального состояния, но не готовая механика прочности. Максимум ограничен снизу единицей, текущее значение — диапазоном 0…максимум.

Существующий `Foundation.GameSession.Boat` не подключён: он относится к отдельной модели сессии. Для будущей интеграции следует назначить единый источник HP и адаптер, передающий подтверждённые изменения контроллеру; не нужно параллельно изменять два независимых состояния. Понижение HP само по себе не останавливает лодку и не включает [скрытое предупреждение](hud-future-indicators.md).

При отсутствии или отключении лодки отображается «Лодка недоступна» и пустая полоса. Экономика и улучшения не подключены.
