# Статус лодки

[Структура HUD](gameplay-hud.md) · [Модель движения](boat-wind-movement.md) · [Сцена](hud-scene-integration.md)

`BoatStatusPanel.Render` получает `BoatController` от корневого HUD и читает публичное состояние той же лодки, которая движется в graybox.

| Данные | Источник | Отображение |
| --- | --- | --- |
| Прочность | `HitPoints`, `MaxHitPoints` | Текущий/максимальный HP и полоса |
| Скорость | `LongitudinalSpeed` | Знаковая скорость, один десятичный знак, минус при ходе назад |
| Парус | `SailPosition`, `SailAngle` | Сложен / частично / полностью, относительный угол |
| Эффективность вперёд | `SailEfficiency` | Захват ветра с положительной продольной проекцией, 0…100% |
| Тип ветра | `Wind.Type`, `Wind.VisualColor` | Штиль / обычный / шторм, цвет плавно меняется вместе с ветром |
| Направление ветра | `Wind.Direction` | Азимут, куда дует ветер |
| Скорость и сила ветра | `Wind.Speed`, `Wind.Strength` | Текущие значения во время плавного перехода |
| Источник тяги | `SailSpeedContribution`, `RowingSpeedContribution` | Парус, гребля вперёд/назад, их сочетание, инерция, стоянка |
| Угол руля | `RudderAngle` | Прямо / влево / вправо и угол в градусах |

Азимут 000° соответствует мировому +Z, 090° соответствует +X. Компас отдельно показывает нос лодки. При отсутствующем или отключённом компоненте ветра выводится «Ветер недоступен». Эффективность описывает геометрию настройки, поэтому может быть ненулевой при сложенном парусе. Фактический вклад сложенного паруса и штиля равен нулю.

Источник хода определяется целевыми вкладами до общего ограничения скорости. Гребля назад распознаётся по отрицательному `RowingSpeedContribution`. При конкурирующих тягах показываются оба источника, знак скорости отражает фактическое движение. Когда вклады отсутствуют и скорость ещё сохраняется, показывается «Инерция», после полной остановки «Стоянка». Текст руля показывает физический угол балки при возврате, дополнительная коррекция курса уже прекращена после отпускания A/D.

Тип штиля объявляется после завершения затухания. При выходе из штиля новый тип показывается с начала плавного нарастания. Цвет названия типа берётся из `VisualColor` через стандартный rich text uGUI. Цвет стрелки Gizmos соответствует тому же состоянию.

Панель расширена до 560 × 310, текст до 528 × 262 для восьми строк. Режим игрока расположен ниже панели с отступом по Y −346. Полоса HP имеет ширину 528 и расположена ниже текста. Обновление выполняет существующий `GameplayHud.LateUpdate`.

Прочность остаётся локальным состоянием `BoatController`, начальные `_hitPoints = 100`, `_maxHitPoints = 100`. Публичный `SetHitPoints(float)` ограничивает значение допустимым диапазоном. Максимум ограничен снизу единицей. Полоса меняет правый якорь `Image` пропорционально HP.

Источники урона и ремонта пока не подключены. Будущий шторм может использовать `WindController.StormIntensity` и `WindTypeChanged` для отдельного компонента урона. Сам ветер HP не изменяет. Существующая `Foundation.GameSession.Boat` относится к отдельной модели сессии, её интеграция требует единого источника состояния. Скрытые [будущие индикаторы](hud-future-indicators.md) сохраняют прежнее поведение.

При отсутствии или отключении лодки отображается «Лодка недоступна» и пустая полоса. Проверки, тесты, Unity и сборка по заданию не запускались, читаемость расширенной панели предстоит оценить вручную.
