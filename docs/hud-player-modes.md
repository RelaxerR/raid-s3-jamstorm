# Режим игрока в HUD

[Структура HUD](gameplay-hud.md) · [Подсказки](hud-interaction-hints.md) · [Исходное управление](graybox-controls.md)

Источник — `PlayerController.ControlMode`. UI отображает текущее значение `PlayerControlMode`. E и Esc обрабатывает `PlayerController`.

| Состояние | Отображение `ControlModeView` | Переход |
| --- | --- | --- |
| `Walking` | Режим: Ходьба · На палубе | При запуске или освобождении станции |
| `Helm` | Режим: Руль · Управление лодкой | Контроллер успешно занял руль |
| `Sail` | Режим: Парус · Управление парусом | Контроллер успешно занял парус |
| `Net` | Режим: Сети | Контроллер успешно занял станцию сетей |

На руле и парусе выход выполняется по E или Esc. На сетях E опускает или поднимает сеть, Esc возвращает ходьбу. При освобождении станции HUD получает обновлённый режим через `LateUpdate`. Пока станция занята, HUD показывает состояние сети и заполнение. При недоступном игроке или лодке показывается «Управление недоступно».

В сцене активен один локальный игрок. [Контекстные подсказки по каждому режиму](hud-interaction-hints.md).
