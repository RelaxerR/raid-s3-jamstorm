# Режим игрока в HUD

[Структура HUD](gameplay-hud.md) · [Подсказки](hud-interaction-hints.md) · [Исходное управление](graybox-controls.md)

Источник — `PlayerController.ControlMode`. Перечисление `PlayerControlMode` не менялось; UI не хранит независимый режим и не обрабатывает E/Esc.

| Состояние | Отображение `ControlModeView` | Переход |
| --- | --- | --- |
| `Walking` | Режим: Ходьба · На палубе | При запуске или освобождении станции |
| `Helm` | Режим: Руль · Управление лодкой | Контроллер успешно занял руль |
| `Sail` | Режим: Парус · Управление парусом | Контроллер успешно занял парус |

При выходе по E/Esc, отключении занятой станции или лодки контроллер возвращает ходьбу, и HUD получает результат в этом же кадре через `LateUpdate`. При недоступном игроке или лодке вместо подсказок режима показывается «Управление недоступно». Это не новый игровой режим.

В сцене активен один локальный игрок. Сетевые состояния, порт и режим вываживания сюда не добавлены. Для нового режима вертикального среза 11 декабря потребуется расширить перечисление, контроллер, `ControlModeView` и [таблицу подсказок](hud-interaction-hints.md).
