## Соответствие текущей реализации

| Требование источников | Решение для текущей задачи |
| --- | --- |
| HP, компас, подсказки станций | Подключены к текущим контроллерам; [статус](hud-boat-status.md), [компас](hud-compass.md), [подсказки](hud-interaction-hints.md) |
| Мини-карта | Схема моря и центра с работающим маркером лодки; полноценная навигация остаётся за рамками задачи — [ограничения](hud-minimap.md) |
| Трюм, трос, прогресс вываживания | Подготовлены выключенные панели без подключения игровых механик — [индикаторы](hud-future-indicators.md) |
| Важные UI-элементы вне крайних 5–10% экрана | Добавлен `SafeArea` с якорями 5%…95%; панели дополнительно отступают внутрь |
| Контекстные подсказки без блокировки игры | Текущая подсказка определяется режимом и доступностью станции, не перехватывает ввод |
| Поэтапный туториал со временем показа | Не реализуется в этой задаче; постоянные подсказки управления не являются одноразовым туториалом |
| Читаемость 16:9 и 21:9 | Якорная раскладка и CanvasScaler; задание ограничивает текущую ручную приёмку 16:9. Работа на 21:9 не подтверждена запуском |
| Сохранения, порт, экономика и экипаж | Исключены прямым заданием; UI их не имитирует |

## Осознанные отличия от полного среза

Архитектурная страница предлагает UI Toolkit, EventBus и будущие системы BoatHealth/FishStorage/WindManager. Конкретное задание требует Canvas, простые Unity UI-элементы, существующие контроллеры и отсутствие лишней событийной инфраструктуры. Поэтому текущий HUD использует uGUI, явные ссылки и контролируемое обновление, без миграции проекта на другой стек.

Текущая лодка — прототип плавания, а не реализация конкретного уровня транспорта из документа среза. Существующая станция паруса сохранена, локальные HP 100/100 не выданы за баланс транспорта первого уровня (в документе 60 HP). Урон, ремонт, ветер, респавн и прогрессия не добавлялись ради UI.

В срезе дух первоначально выступает опасностью с преследованием; активное вываживание духа относится к третьему уровню и дополнительному объёму. Скрытая панель прогресса не подразумевает, что этот объём уже реализован или обязателен для ближайшего показа.

Сопоставление выполнено по текстам документов и реализации. По указанию пользователя Unity, сборка, тесты и автоматические проверки проекта не запускались.
