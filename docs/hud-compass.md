# Компас

[Структура HUD](gameplay-hud.md) · [Мини-карта](hud-minimap.md) · [Интеграция](hud-scene-integration.md)

`CompassView` закреплён сверху по центру Canvas. `GameplayHud` передаёт ему `BoatController.transform.forward` после движения. Направление вычисляется через `Atan2(forward.x, forward.z)` и приводится к 0…360°. UI показывает восемь секторов и округлённые градусы: например «КУРС СВ 045°». Округление через север выводит 000°, а не 360°.

Соглашение graybox: мировой +Z — север, +X — восток, −Z — юг, −X — запад. Показывается направление носа, в том числе на стоящей лодке. Сейчас движение идёт вдоль +Z самой лодки, поэтому в ходе направление носа совпадает с направлением движения. Курс не зависит от камеры и игрока. При недоступной лодке выводится «КУРС —».

Это минимальный рабочий компас без текстур и внешних ассетов. Вложенный `FutureDirectionMarkers` выключен, доступен через `CompassView.FutureMarkers`. Для среза 11 декабря здесь можно разместить ветер и направления целей. Их источники, вид и способ проекции ещё не реализованы; текущий текст курса продолжит работать независимо.
