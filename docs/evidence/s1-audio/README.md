# Сигналы подбора и угрозы в миксе 0.1.3

Два фрагмента записаны с итогового аудиовыхода диагностического macOS Player 0.1.3, 48 кГц, стерео. Уровни сохранены при экспорте в MP3. В начале обоих фрагментов слышен морской фон.

| Фрагмент | Момент события от начала фрагмента | Средний уровень фона перед событием | Средний уровень микса в момент события |
|---|---|---:|---:|
| [Рыба на палубе → бочка](pickup.mp3), 3,8 с | 1,55 с — подбор, 1,74 с — укладка. Игровая сессия зарегистрировала одну рыбу в грузе. | −57,5 dBFS | −41,1 dBFS |
| [Появление духа](threat.mp3), 5,5 с | 1,55 с — рёв. Для воспроизведения эпизода контрольный сценарий заполнил груз, в логе Player зарегистрированы создание духа и воспроизведение его источника. | −60,7 dBFS | −33,1 dBFS |

Сигналы подбора, укладки и угрозы обнаруживаются в реальном миксе по форме волны. Для сверки исходные клипы и запись приведены к моно, отфильтрованы ниже 150 Гц и пересчитаны на 4 кГц. Максимумы нормированной взаимной корреляции составили 0,74 для `sfx_fish_pickup`, 0,79 для `sfx_barrel_insert` и 0,99 для `sfx_spirit_roar_chase`.

Уровни в таблице измерены отдельно по исходной стереозаписи без фильтрации, до кодирования в MP3. Окна RMS в первой записи — 23,20–24,60 с и 24,75–25,25 с, во второй — 2,40–3,80 с и 3,95–6,13 с. Подбор с укладкой выделяется над фоном на 16,4 дБ, появление духа — на 27,6 дБ. Пики в этих эпизодах составили −15,6 и −18,1 dBFS соответственно.

Субъективную различимость и баланс в наушниках или на колонках можно оценить по приложенным фрагментам. Слепое прослушивание с участником остаётся частью [#44](https://github.com/RelaxerR/raid-s3-jamstorm/issues/44).
