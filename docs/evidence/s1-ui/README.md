# Лавка и HUD в финальной сборке S1

Диагностический macOS Player 0.1.3 собран в Unity 6000.5.1f1 из [7d06301](https://github.com/RelaxerR/raid-s3-jamstorm/commit/7d063014945880ef90c8bb1471a0285eb19cd6e3). Сценарий запущен из Boot при двух разрешениях. Кадры сняты с экрана Player. Контрольные состояния подготовлены в отдельной копии проекта.

| Сценарий | 1280×720 | 1920×1080 |
|---|---|---|
| Лавка сразу после старта, 0 монет | [Кадр](shop-unavailable-1280.webp) | [Кадр](shop-unavailable-1920.webp) |
| Лавка после продажи, 100 монет | [Кадр](shop-available-1280.webp) | [Кадр](shop-available-1920.webp) |
| Уникальная рыба, место на палубе занято | [Кадр](occupied-1280.webp) | [Кадр](occupied-1920.webp) |
| Подсказка подбора возле станции при крене | [Кадр](roll-hint-1280.webp) | [Кадр](roll-hint-1920.webp) |
| Смена значка станции, фрагменты HUD сверху вниз — руль, сети, гарпун | [Фрагменты](stations-1280.webp) | [Фрагменты](stations-1920.webp) |

При 1280×720 луч от камеры достигал 8 рыб вне панели подсказки, при 1920×1080 — 9. Измеренный крен составлял 11,98° и 11,99° соответственно. В обеих конфигурациях полностью видны вопрос о замене и обе кнопки.

## Как воспроизвести

1. Начать новую игру и открыть лавку. При нулевом балансе кнопки покупки затемнены. После продажи десяти лазурных рыб за 100 монет доступны улучшение скорости и древесина. Сценарий готовил контрольный улов через API сессии и продавал только лазурную рыбу, сохраняя багряную на палубе.
2. По очереди занять руль, сети и гарпун. Проверить название режима и пиктограмму в левой части HUD. Доставить рыбу сетью на палубу и встать возле станции. В кадре с наклоном корпуса видны рыба и подсказка «ЛКМ по рыбе — в бочку». Для повторяемости сценарий задавал крен около 12° и проверял луч от игровой камеры к рыбам с учётом перекрытия панелью подсказок.
3. Оставить багряную рыбу на палубе и в новом рейсе открыть карточку следующей рыбы. Проверить вопрос «Заменить тушу на палубе?» и обе кнопки — «Отпустить» и «Заменить». Для снимка Player сценарий выставлял состояние зафиксированной рыбы и открытой карточки. Последовательность вываживания, отпускания и замены с игровым вводом прошёл PlayMode-сценарий `CatchCardReleasesKeepsAndReplacesOneCarcassAcrossVoyages` на 61b42b7. В 7d06301 изменился номер версии.
