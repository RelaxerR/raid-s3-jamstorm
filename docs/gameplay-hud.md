# Игровой HUD graybox

[Оглавление](index.md) · [Подключение к сцене](hud-scene-integration.md) · [Управление лодкой](graybox-controls.md)

## Объём

HUD поддерживает ближайший показ плавания и оставляет точки расширения для вертикального среза 11 декабря 2026. Контракт UI v2 взят из задания на эту реализацию. Отдельный документ v2 в репозитории не найден, ссылка на него не предоставлена; соответствие дополнительным требованиям отдельной редакции v2 не подтверждено. Прочитан общий GDD Second Catch в Яндекс Вики (страница 50615518, ревизия 77413538); он не обозначен как v2 и не заменяет UI-контракт задания.

Работают представления текущего режима, доступной станции, скорости, паруса, команды движения и курса лодки. Мини-карта является схемой с работающим маркером лодки. HP берётся из нового публичного состояния `BoatController`, начальное значение 100/100; источника игрового урона пока нет. Рыбалка, экономика, контракты, инвентарь, сохранения, кооператив, мультиплеер и меню порта не добавлены.

## Структура

Все классы находятся в `Assets/Scripts/Runtime/UI`, namespace `SecondCatch.UI`, сборка `Runtime`. Для стандартных `Text` и `Image` в `Runtime.asmdef` добавлена ссылка `UnityEngine.UI`. Дополнительных пакетов и внешних ассетов нет.

| Компонент | Ответственность | Документ |
| --- | --- | --- |
| `GameplayHud` | Явные ссылки на источники и представления; обновление после движения | [Интеграция](hud-scene-integration.md) |
| `BoatStatusPanel` | HP, скорость, парус, ход и руль | [Статус лодки](hud-boat-status.md) |
| `ControlModeView` | Читаемый режим и предмет управления | [Режим игрока](hud-player-modes.md) |
| `InteractionHintView` | Подсказки текущего режима и доступной станции | [Взаимодействия](hud-interaction-hints.md) |
| `CompassView` | Курс носа лодки | [Компас](hud-compass.md) |
| `MinimapView` | Схема моря и проекция лодки | [Мини-карта](hud-minimap.md) |
| `FutureGameplayIndicators` | Выключенные места будущих механик | [Индикаторы среза](hud-future-indicators.md) |

`GameplayHud.LateUpdate` читает контроллеры и вызывает публичные `Render` представлений. `BoatController.Update` с порядком 100 к этому моменту уже применил движение. UI не читает клавиатуру и не посылает игровые команды. Событийная шина, поиск объектов сцены и отдельная игровая модель HUD не вводились.

`GameplayHud.Bind(boat, player, mapCenter)` позволяет подключить тот же префаб в другой сцене. Дочерние представления используют свои сериализованные ссылки; нажатия продолжают обрабатываться в существующей системе ввода.

## Представление

Canvas: Screen Space Overlay, порядок 10. CanvasScaler: Scale With Screen Size, 1920 × 1080, Match 0.5. Раскладка рассчитана на 16:9: слева сверху статус и режим, по центру сверху курс, справа сверху мини-карта, снизу по центру контекстная подсказка. Панели нейтральные, текст светлый, элементы не перехватывают мышь.

Используется стандартный uGUI и встроенный шрифт Unity. `GameplayHud.Awake` назначает `LegacyRuntime.ttf` всем дочерним `Text`, включая выключенные заготовки, для русского текста без импорта шрифтов. HUD содержит только информацию: EventSystem и GraphicRaycaster ему не нужны. Для будущих кнопок их потребуется добавить отдельно.

По просьбе пользователя проверки, тесты, Unity и сборка не запускались. Читаемость и поведение в редакторе ещё не подтверждены ручным запуском.
