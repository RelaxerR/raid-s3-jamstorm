# Игровой HUD graybox

[Оглавление](index.md) · [Подключение к сцене](hud-scene-integration.md) · [Управление лодкой](graybox-controls.md)

## Объём

HUD поддерживает ближайший показ плавания и оставляет точки расширения для вертикального среза 11 декабря 2026. Актуальные страницы среза, архитектуры, механик и UI получены через API с использованием `tools/wiki.py`. [Источники и соответствие требованиям](hud-design-sources.md) фиксируют ссылки, ревизии, выбранный объём и отличия от полного среза. Приоритет имеют конкретные ограничения задания: Canvas, простые Unity UI-компоненты, существующая структура проекта и обновление без новой событийной системы.

Работают представления текущего режима, доступной станции, скорости, трёх положений и угла паруса, эффективности вперёд, типа и направления ветра, передней/обратной гребли, угла руля и курса лодки. Мини-карта является схемой с работающим маркером лодки. HP берётся из нового публичного состояния `BoatController`, начальное значение 100/100; источника игрового урона пока нет. Рыбалка, экономика, контракты, инвентарь, сохранения, кооператив, мультиплеер и меню порта не добавлены.

## Структура

Все классы находятся в `Assets/Scripts/Runtime/UI`, namespace `SecondCatch.UI`, сборка `Runtime`. Для стандартных `Text` и `Image` в `Runtime.asmdef` добавлена ссылка `UnityEngine.UI`. Дополнительных пакетов и внешних ассетов нет.

| Компонент | Ответственность | Документ |
| --- | --- | --- |
| `GameplayHud` | Явные ссылки на источники и представления; обновление после движения | [Интеграция](hud-scene-integration.md) |
| `BoatStatusPanel` | HP, знаковая скорость, три положения/угол/эффективность паруса, тип и цвет ветра, источники тяги, угол руля | [Статус лодки](hud-boat-status.md) |
| `ControlModeView` | Читаемый режим и предмет управления | [Режим игрока](hud-player-modes.md) |
| `InteractionHintView` | Подсказки текущего режима и доступной станции | [Взаимодействия](hud-interaction-hints.md) |
| `CompassView` | Курс носа лодки | [Компас](hud-compass.md) |
| `MinimapView` | Схема моря и проекция лодки | [Мини-карта](hud-minimap.md) |
| `FutureGameplayIndicators` | Выключенные места будущих механик | [Индикаторы среза](hud-future-indicators.md) |

`GameplayHud.LateUpdate` читает контроллеры и вызывает публичные `Render` представлений. `BoatController.Update` с порядком 100 к этому моменту уже применил движение. UI не читает клавиатуру и не посылает игровые команды. Событийная шина, поиск объектов сцены и отдельная игровая модель HUD не вводились.

`GameplayHud.Bind(boat, player, mapCenter)` позволяет подключить тот же префаб в другой сцене. Дочерние представления используют свои сериализованные ссылки; нажатия продолжают обрабатываться в существующей системе ввода.

## Представление

Canvas: Screen Space Overlay, порядок 10. CanvasScaler: Scale With Screen Size, 1920 × 1080, Match 0.5. Раскладка рассчитана на 16:9: слева сверху статус и режим, по центру сверху курс, справа сверху мини-карта, снизу по центру контекстная подсказка. Все панели помещены в `SafeArea`: якоря (0.05, 0.05)…(0.95, 0.95), то есть минимум 5% отступа с каждой стороны плюс внутренние отступы панелей. Это учитывает R4 документа UI. Панели нейтральные, текст светлый, элементы не перехватывают мышь.

Используется стандартный uGUI и встроенный шрифт Unity. `GameplayHud.Awake` назначает `LegacyRuntime.ttf` всем дочерним `Text`, включая выключенные заготовки, для русского текста без импорта шрифтов. HUD содержит только информацию: EventSystem и GraphicRaycaster ему не нужны. Для будущих кнопок их потребуется добавить отдельно.

По просьбе пользователя проверки, тесты, Unity и сборка не запускались. Читаемость и поведение в редакторе ещё не подтверждены ручным запуском.

## HP, повреждение и возврат

`BoatStatusPanel` читает текущий/максимальный HP через публичный API лодки, состояние повреждения через `BoatHealth`, состояние возврата через `IsRespawning`. Полоса окрашивается по прочности, после контакта на 1.2 с меняет цвет и показывает снятые HP. При нуле строка движения сообщает «Лодка возвращается в порт», после возврата отображаются полные HP. `GameplayHud` приостанавливает доступность управления игрока во время возврата. Используются существующие панель, текст и полоса. Детали приведены в [статусе лодки](hud-boat-status.md) и [механике волн и HP](boat-waves-buoyancy.md).
